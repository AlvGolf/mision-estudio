# Misión Estudio

Juegos de estudio para primaria, con ranking compartido.

- Web: https://alvgolf.github.io/mision-estudio/
- Cada juego vive en su carpeta (`ingles-u2/`) y se enlaza desde `index.html`.
- El ranking se guarda en una hoja de Google mediante el script de `apps-script/Code.gs` (copia de referencia; el que funciona está en Google Apps Script).

## Trabajar en local

```
cd $HOME\Documents
git clone https://github.com/AlvGolf/mision-estudio.git
cd mision-estudio
claude
```

Las reglas del proyecto y el flujo de trabajo están en `CLAUDE.md`. Siempre `git pull` antes de empezar.
